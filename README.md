Bank Account Management System

📌 Project Overview

The Bank Account Management System is a Java-based desktop application developed to manage basic banking operations. It provides a simple graphical user interface for users to perform banking activities such as creating accounts, managing account details, and handling transactions.

The project uses Java Swing for the user interface and Oracle Database for storing and managing banking information.

🚀 Features

- Create and manage bank accounts
- Store and retrieve customer information
- Deposit money into an account
- Withdraw money from an account
- Check account balance
- Manage banking transactions
- Database connectivity using JDBC
- User-friendly graphical interface using Java Swing

Note: The features listed above should match the functionality implemented in your source code.

🛠️ Technologies Used

- Programming Language: Java
- GUI Framework: Java Swing
- Database: Oracle Database
- Database Connectivity: JDBC
- IDE: Eclipse
- Build Tool: Apache Ant

⚙️ Prerequisites

Before running the application, make sure you have installed:

- Java Development Kit (JDK)
- Oracle Database or Oracle Database Express Edition
- Oracle JDBC Driver
- NetBeans IDE or another compatible Java IDE

▶️ How to Run the Project

1. Clone or download this repository.
2. Open NetBeans IDE.
3. Select File → Open Project.
4. Choose the "Bank-Account-Management" project folder.
5. Configure the Oracle database connection.
6. Verify that the Oracle JDBC driver is available in the project libraries.
7. Run the project from the IDE.

🗄️ Database Configuration

1. Start your Oracle Database service.
2. Create the required database user and tables.
3. Configure the database connection details in the Java source code.
4. Verify that the application can connect to the database before running it.

Security note: Never commit real database passwords or sensitive credentials to a public repository.
